# DYLAN · 黄冬冬个人作品网站

无构建依赖的响应式静态网站，包含品牌案例、专业能力、工作经历与联系入口。

## 本地运行

在 `/workspace/JSP` 执行：

```sh
python3 -m http.server 8000 --bind 127.0.0.1
```

在本机浏览器访问 `http://127.0.0.1:8000`。

## 内容与素材

- 内容依据用户提供的 2026 简历与作品集，N/OWN 明确标注为自主概念品牌。
- 页面不再展示 PDF 整页截图。品牌理念、标识规格、七级灰阶及规则以原生 HTML 重排；`assets/nown-wordmark.svg` 仅提取 PDF 中的正式标识矢量轮廓，未用字体重绘。原有 PNG 保留为历史素材，页面不再引用。
- 参考手册基础灰阶：#222424、#565856、#B7B8B5、#D7D8D3、#F0EFEB。
- 字体优先使用本机 MiSans，未附带字体文件，其余系统中文字体回退。
- 作品集八个系列保留 34 个空图位，显示文件名和尺寸，可按方向筛选、按系列折叠。图片及视频未提供的位置没有使用虚构成品。
- 邮箱和电话为直接链接，微信支持复制及失败提示。页面未公开薪资预期或提供原始简历下载。

`index.html` 修改内容，`style.css` 修改样式，`script.js` 管理作品筛选、手机菜单、当前章节提示、阅读进度和微信复制。品牌规则使用原生 details 展开。无需数据库或 API 密钥。本轮未部署或发布。

品牌系统按四块展示：品牌核心（手册第 3 页）、标识系统（第 5 页四套设计稿）、辅助图形（第 8 页开放轨迹）、应用（第 29 页三个真实素材空位）。图形从原始 PDF 中分区提取为 SVG，标题和说明以 HTML 重排，不使用整页截图。之前扩展的字体、栅格及执行规范已从品牌板块移除。

应用占位按 3:2、9:16、4:3 原比例等高缩放，桌面并排、手机纵向排列。KELEIAO 和虎骑士已并入作品系列，共用商业项目筛选、折叠和空图位样式。
